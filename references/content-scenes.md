# 四种场景的策划与验收

## 个人学习 learning

按[学习 Prompt](../prompts/scenes/learning.txt)先选核心知识及必要前提，再按概念依赖组织连续长文。重要知识讲到能解释依据、完成简单应用或变化判断；背景只补到能接上主线，不追求原稿分支全部展开。关键推理与条件留在主线，额外证明和变体按收益决定是否补充；涉及张量时说明关键形状变化及作用，不逐句翻译代码。检查覆盖、解释与删减是否服务于既定目标，不以长篇幅代表详细，也不以提纲代表精简。

HTML 使用可收起的左侧分层目录、舒适阅读宽度和清楚的章节间距。检查首屏、章节交界、主要图解、公式、代码和结尾，验证目录定位/收起、阅读进度与图标主题切换。默认交连续HTML，检查截图不是正文长图。

## 技术博客 blog

围绕明确论点组织叙述，开篇交代问题及核心判断，再给机制、证据、例子和适用边界。标题直接表达主题，不制造悬念。保留连续段落；来源靠近所支持的论断，真实证据和教学构造分开。作者、日期、经历只写实际给出的信息。

HTML与学习共用阅读模板，内容按论点与证据组织，详略服从独立读者的判断需要；不另设右侧目录或独立版式。检查导语、连续阅读节奏、图文衔接、来源、两种主题和结尾；不强制小红书的标题/配文文件。

## 技术汇报 report

先明确听众要形成的判断与时长，再选择证据和讲解顺序。每页一个讲解任务，页标题表达本页主张，正文保留必要条件；备注补充口头解释，不承载理解结论必须看到的证据。适合用局部机制图、对照表和原证据支持取舍，不把文章机械切片。

默认1280×720。目录可直达，←/→及PageUp/PageDown翻页，Home/End到首末页，N显示备注，Esc收起浮层。切换主题保留当前页。每页核对安全区、页脚、图内字号、公式和条件；两种主题都检查，最终PNG使用用户选定主题，默认浅色。

## 小红书 rednote

按[小红书 Prompt](../prompts/scenes/rednote.txt)围绕明确的小主题，用少量、通俗且连贯的文字讲清核心机制。图片内完整的是所选问题的解释，不是原稿全部内容；可略难推导，不能略关键理由与适用条件。总量过大先删减与收窄非必需范围，必要解释仍放不下再按语义增页，配文仅作摘要。沿用[原小红书流程](rednote-scene.md)及原渲染器，浅暖米色academic主题、3:4、1080×1440 CSS px、DPR2。检查全部图片、公式、几何、条件、页码与手机可读性。只图请求按指定范围执行；新长文和汇报模板不覆盖其画幅、字体或视觉设置。
