# 四种场景的策划与验收

## 个人学习 learning

按概念依赖组织连续长文，按需要安排问题与整体机制、必要定义、例子、关键步骤和推导、实现联系与边界，不要求每篇具备全部环节。涉及张量或数据时说明关键形状变化及其作用，不逐句翻译代码；概念性材料讲清分类依据与概念联系。图解确有解释价值时放在卡点附近，读者不必跨页找变量定义。只有有学习价值时才加练习，不凑章节和图数。

HTML 使用可收起的左侧分层目录、舒适阅读宽度和清楚的章节间距。检查首屏、章节交界、主要图解、公式、代码和结尾，验证目录定位/收起、阅读进度与图标主题切换。默认交连续HTML，检查截图不是正文长图。

## 技术博客 blog

围绕明确论点组织叙述，开篇交代问题及核心判断，再给机制、证据、例子和适用边界。标题直接表达主题，不制造悬念。保留连续段落；来源靠近所支持的论断，真实证据和教学构造分开。作者、日期、经历只写实际给出的信息。

HTML与学习共用阅读模板，内容按论点与证据组织，详略服从独立读者的判断需要；不另设右侧目录或独立版式。检查导语、连续阅读节奏、图文衔接、来源、两种主题和结尾；不强制小红书的标题/配文文件。

## 技术汇报 report

先明确听众要形成的判断与时长，再选择证据和讲解顺序。每页一个讲解任务，页标题表达本页主张，正文保留必要条件；备注补充口头解释，不承载理解结论必须看到的证据。适合用局部机制图、对照表和原证据支持取舍，不把文章机械切片。

默认1280×720。目录可直达，←/→及PageUp/PageDown翻页，Home/End到首末页，N显示备注，Esc收起浮层。切换主题保留当前页。每页核对安全区、页脚、图内字号、公式和条件；两种主题都检查，最终PNG使用用户选定主题，默认浅色。

## 小红书 rednote

沿用[原小红书流程](rednote-scene.md)及原渲染器，浅暖米色academic主题、3:4、1080×1440 CSS px、DPR2。正文完整呈现在图片中，配文仅作摘要。容量不足按完整语义增页；检查全部图片、公式、几何、条件、页码与手机可读性。只图请求按指定范围执行。新长文和汇报模板不覆盖其画幅、字体或视觉设置。
