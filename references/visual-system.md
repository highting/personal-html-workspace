# 成品视觉与实际验收

Prompt 给出策划方向，成品决定是否需要调整。材料准确、原稿只读、用户指定范围与交付格式是边界；讲解顺序、图数、章节数和版式是起点。先生成代表性的标题区、密集正文与主要图解，实际查看后修正，再制作全篇。检查结果和调整理由留在 `delivery.md`，不写进读者看到的正文或图片。

## 一套语义配色

HTML 的颜色在 `assets/content/content.css` 定义。新制 SVG 使用这些变量，不另配一套亮色；独立图片无法继承网页变量，制作前将对应主题的实际色值写进图面说明。小红书继续使用 academic 浅色，画幅和字体不随长文模板变化。

| 角色 | 浅色 | 深色 | CSS 变量 |
|---|---|---|---|
| 页面底色 | `#F7F4ED` | `#171D27` | `--bg` |
| 标题、界面与图中标签 | `#263238` | `#E5EAF2` | `--text` |
| 学习/博客正文、公式与代码普通文字 | `#263238` | `#D6DEEA` | `--reading-text` |
| 次要文字 | `#586571` | `#ACB8CA` | `--muted` |
| 主体 / 主路径 | `#3B5BDB` | `#A5B7FF` | `--accent` |
| 主体浅填充 | `#EEF2FF` | `#29334D` | `--accent-soft` |
| 对照线条 | `#D97706` | `#F0BC79` | `--compare` |
| 对照浅填充 | `#FFF7ED` | `#3B2E22` | `--compare-soft` |
| 第三对象线条 | `#0891B2` | `#76D5E8` | `--secondary` |
| 第三对象浅填充 | `#ECFEFF` | `#18343D` | `--secondary-soft` |

通常只启用主体和对照两色。橙色、青色用于几何线条与填充，图中普通小字使用`--text`；颜色之外用文字、线型或位置区分对象。数值图保留统一坐标和比例。

深色长文用略柔和的正文亮度与标题形成层级，正文仍保持400字重；导语和图注沿用次要文字色。字号、字重、实际字体和亮度分别核对，不因深色截图显得更重就直接降低字重。阅读文字色只作用于共享长文正文，不改变汇报或小红书配色。

普通流程节点使用暖灰底 `--node-bg: #EAE7DE` 和细描边 `--node-line: #C8C5BB`，深色分别为 `#2A323E` 与 `#536072`。不要给每个普通节点铺蓝紫色；强调色主要用于路径、关键对象或确有语义的区域，减少与暖米色页面冲突的色块。

自绘图置于 `figure`。`.diagram-fill` 为普通节点暖灰底，`.diagram-line` 为主体路径色；`.diagram-emphasis-fill` 仅用于需要强调的主体区域。对照使用 `.diagram-compare` / `.diagram-compare-fill`，第三对象使用 `.diagram-secondary` / `.diagram-secondary-fill`。箭头填充可写 `fill="var(--accent)"`。样式只作用于自绘 SVG，不能覆盖 KaTeX 内部 SVG。图中文字按最终显示大小核对，不能只看viewBox内的字号。

小红书academic主题为内嵌SVG提供共享图形颜色变量与`.diagram-*`类，将主体、对照、文字等角色映射到原`--academic-*`配色，普通节点采用同一暖灰。仅共享颜色接口，原卡片字体、画幅和排版继续沿用；图形布局与字号仍须按小红书的最终显示尺寸重排，可参考`demos/academic-palette.md`。作为图片引用的SVG不能继承宿主变量或类规则，应在文件内明确设置颜色与样式；需要随网页主题切换时选择内联SVG，或明确提供两套主题资源。

新制位图优先采用透明背景，或使用与网页协调的浅暖纸色图面；固定浅底图使用 `figure.media-plate`，在深色网页上保留完整浅色图面和清楚边界。需要双主题原生图时，分别制作两张并用 `.theme-light` / `.theme-dark` 切换。不得用滤镜反色原始证据图，也不得声称固定图片会自动适配主题。生图 prompt 分开写“准确上图文字”与“构造说明”，不让坐标、像素数值、草稿说明进入图片。

## 字号服从阅读尺寸与内容

学习和博客共用一套阅读模板，主要区别是内容详略，不为场景另建布局。以18px正文、舒适行长为起点；读者可调到16–24px，标题、表格、图注和公式随正文保持层级。图片与SVG可点击或按Enter放大，原图注中的条件、公式和链接随图保留；支持按宽高适合窗口、进一步放大、键盘滚动、Esc关闭和返回原阅读位置与焦点。放大视图标题标明当前图像，缩放状态清楚；正文仍保留原图注，无图注的图像不继承上一张说明。标题换行自然，短导语不制造大空白，不每段套容器。代码允许局部横向滚动；长公式优先合理断行，静态图片不能依赖滚动。

长文视觉优先调整标题、导语、章节分隔和阅读节奏：工具栏与正文外边界对齐，场景身份只在工具栏出现，标题区由标题、导语及真实已给的作者/日期构成。图注与图形成组，正文和图注通过字号与留白区分。表格使用浅表头、横向分隔和克制的行间距；代码的语言、文件名与复制操作放在独立工具栏，重点行轻量标记。不能用更多色块、徽章或装饰动画代替层级设计。

公式默认正常展示，按主线选择少量核心关系强调；定义、证明中的中间式和重复引用不自动加框。需要网页级重点时复用`.callout`的中性底色与细强调边，不在内部再叠加黑色公式框；只删除纯排版的框命令，保留数学关系及条件。长文公式外部间距随正文字号变化，重点块内用较紧凑的间距，保留公式本身的排版高度及上下安全留白。调整工作稿的强调时核对变量、运算、条件和公式数量，不修改数学含义。原稿中的排版标记不应成为所有公式同级强调的硬约束。

短行内公式按整体排布，当前行尾空间不足时移到下一行，避免把括号和核心关系割裂。公式宽度限制在正文容器内，较长表达式仍保留合法断行；不对所有公式强制nowrap。实际查看大字号的行内根号、分式及多项表达式，必要时将过长表达式改为合理的独立公式。

长文自绘图仅在图面设置中性底色和边框，图注在下方与正文左边界对齐，用较小字号和紧邻留白形成一组；图注不再重复加分隔线。固定浅底证据图保留`media-plate`的完整图面。文末来源可用`.article-sources`独立整理，标题与出处分行、正常字形，不把长篇出处整段斜体化；保留原链接、图示来源和适用条件。论断附近的引用仍就近放置，不能全部搬到文末。

表格中的纯数值列按内容选择右对齐，使用等宽数字方便逐列比较；说明文字和混合公式列保持自然阅读对齐，不自动猜测所有列的类型。Markdown可用`---:`指定右对齐。表头和表格内的短代码保持完整，空间不足用表格局部滚动，避免拆出孤字或割裂数组表示；表头本身应简短。只在溢出时显示次要字号的滚动方向提示，在表格下方保留相应间距，不遮挡单元格或伸出补充内容面板；方向变化不移动正文。多表格、多代码长文的缩放截图应覆盖各个块，不能只查看每类第一个块。

目录用章节编号、分组间距和小节缩进呈现层级，编号不进入正文标题。当前小节同时标明所属章节；目录过长时只滚动目录容器以保持当前项可见。文末的短结尾也应被正确选中。引言可略大于正文，但不重复增加彩色容器。

小红书1080px画布以38px正文、44–48px小标题为起点；390px展示时38px约为13.7px。图标签优先接近正文阅读大小，低于12px应重排，不能依赖放大；页码可较小。正文、图解和条件按内容分配空间，横向关系过小则重构图，不用装饰文字填空。汇报以24–28px正文、约42px标题为起点，必要图标签至少18px，并查看完整1280×720导出。

汇报标题页可显式选用`slide-cover`：56px主标题、自然换行和居中的内容组，简短导语用次要文字色；正文页保持原标题与证据层级。封面不是默认的第一页类型，也不通过缩字或裁切装入过量内容。

汇报的独立机制图可用`figure.report-figure`：图面默认280px高、16px内边距，图注18px并紧邻图面。默认高度是起点，简单流程可同步调整SVG的viewBox和显示高度，减少无效空白；标签按最终比例核对，保持图形比例，不能把长文图直接缩小后交付。标题、图、图注须一起落在正文安全区；复杂图应拆页或调整构图，不靠继续缩小必要标签。原生缩放逐页检查，并覆盖各图放大和关闭后的页序。

## 成品检查闭环

- 长文与汇报以桌面使用为目标，不另做手机适配验收。检查浅色、深色下的首屏、全部正文区、图解、公式、表格、代码、结尾。核对100%、150%、200%缩放，字号调节与图片放大；需区分真实浏览器缩放、CSS布局缩放和DPR，只记录实际执行方式。整页截图供覆盖核对，分屏截图用于细读；章节标题截图不代表整章已看完。
- 汇报查看全部明暗页及所选主题PNG；小红书查看全部原图和390px宽预览，核对上下文、页序和最终读者可见文案。
- 搜索“稿子示例”“排版示例”“占位文案”“待补充”“此处插入”等制作残留并结合上下文判断。正常代码示例、必要教学标注和真实来源保留；不能靠删除证据边界让文案看起来干净。
- 机器检查记录边界、实际SVG标签大小、颜色对比度和可疑文案；位图内文字、信息密度、技术关系与美观仍须目视核对。文字对比度检查不等于完整无障碍认证。
- 修改正文、HTML或图片后重新检查。只有机器检查通过、可疑项处理完成且所有成品实际查看后，才标记 `completed` 并汇总短路径。
- 阅读功能随视觉一起检查：代码复制与换行保真、章节链接直达、折叠区内公式、续读提示及恢复位置。默认折叠和全部展开都要查看，避免把隐藏内容漏出检查范围。
- 字号测试在长文中追踪当前文字，不只检查控件数字变化；原生缩放截图还要核对像素尺寸和实际画面，避免错误裁图得到空白或截断截图却被计作通过。
