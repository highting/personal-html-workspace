# 成品视觉与实际验收

Prompt 给出策划方向，成品决定是否需要调整。材料准确、原稿只读、用户指定范围与交付格式是边界。学习、博客主要优化文稿质量与有效图片密度，按重要知识段复核图解覆盖，复用现有排版并修复实际可读性问题。小红书、汇报首先优化视觉效果，其次校准文稿重点与详略：内容稿稳定后，先制作开篇、主要图解或证据页、最密集页，实际检查层级、对齐、留白与视觉重心，修正后再制作全篇；全篇缩略浏览还应有清楚的节奏，同类页面保持一致。讲解顺序、图数、章节数和版式按内容决定，不为了版式变化增加页面。检查结果和调整理由留在 `delivery.md`，不写进读者看到的正文或图片。

## 按场景选择外观，共用语义配色

学习/博客的颜色在 `assets/content/content.css` 定义，保留浅色「纯白、纸白、暖米」与深色「石墨、午夜蓝、暖墨」，默认暖米/午夜蓝，浅深偏好分别记忆。汇报默认纯白，只提供纯白 `#FFFFFF` 与纸白 `#FAF9F6` 背景，使用独立记忆，不读取长文的明暗或配色偏好；不提供深色及明暗样张。小红书使用 academic 纸白 `#FAF9F6`，不用纯白或深色。下表仍是学习/博客的暖米/午夜蓝基线；汇报与小红书沿用相同语义角色，采用各自场景色值。新制SVG使用这些变量；独立图片无法继承网页变量，制作前将实际色值写进图面说明。

| 角色 | 浅色 | 深色 | CSS 变量 |
|---|---|---|---|
| 页面底色 | `#F7F4ED` | `#171D27` | `--bg` |
| 标题、界面与图中标签 | `#263238` | `#E5EAF2` | `--text` |
| 学习/博客正文、公式与代码普通文字 | `#263238` | `#D6DEEA` | `--reading-text` |
| 次要文字 | `#586571` | `#ACB8CA` | `--muted` |
| 主体 / 主路径 | `#3B5BDB` | `#A5B7FF` | `--accent` |
| 主体浅填充 | `#EEF2FF` | `#29334D` | `--accent-soft` |
| 对照线条 | `#D97706` | `#F0BC79` | `--compare` |
| 对照浅填充 | `#FFF7ED` | `#3B2E22` | `--compare-soft` |
| 第三对象线条 | `#0891B2` | `#76D5E8` | `--secondary` |
| 第三对象浅填充 | `#ECFEFF` | `#18343D` | `--secondary-soft` |

通常只启用主体和对照两色。橙色、青色用于几何线条与填充，图中普通小字使用`--text`；颜色之外用文字、线型或位置区分对象。数值图保留统一坐标和比例。

深色长文用略柔和的正文亮度与标题形成层级，正文仍保持400字重；导语和图注沿用次要文字色。字号、字重、实际字体和亮度分别核对，不因深色截图显得更重就直接降低字重。阅读文字色只作用于共享长文正文，不改变汇报或小红书配色。

普通流程节点使用暖灰底 `--node-bg: #EAE7DE` 和细描边 `--node-line: #C8C5BB`，深色分别为 `#2A323E` 与 `#536072`。不要给每个普通节点铺蓝紫色；强调色主要用于路径、关键对象或确有语义的区域，减少与暖米色页面冲突的色块。矩阵、向量条和缓存整体采用小圆角外轮廓，内部格子保持规整直分隔；不把每个小格都做成圆角胶囊。独立 token 与实际操作模块可略圆，半径随对象尺寸保持克制。仅对表达容器的边界作此处理，坐标轴、数值长度与精确几何不随之圆化。

自绘图置于 `figure`。`.diagram-fill` 为普通节点暖灰底，`.diagram-line` 为主体路径色；`.diagram-emphasis-fill` 仅用于需要强调的主体区域。对照使用 `.diagram-compare` / `.diagram-compare-fill`，第三对象使用 `.diagram-secondary` / `.diagram-secondary-fill`。箭头填充可写 `fill="var(--accent)"`。样式只作用于自绘 SVG，不能覆盖 KaTeX 内部 SVG。图中文字按最终显示大小核对，不能只看viewBox内的字号。

小红书academic主题为内嵌SVG提供共享图形颜色变量与`.diagram-*`类，将主体、对照、文字等角色映射到原`--academic-*`配色，普通节点采用同一暖灰。仅共享颜色接口，原卡片字体、画幅和排版继续沿用；图形布局与字号仍须按小红书的最终显示尺寸重排，可参考`demos/academic-palette.md`。作为图片引用的SVG不能继承宿主变量或类规则，应在文件内明确设置颜色与样式；需要随网页主题切换时选择内联SVG，或明确提供两套主题资源。

新制位图优先采用透明背景，或使用与网页协调的浅暖纸色图面；固定浅底图使用 `figure.media-plate`，在深色网页上保留完整浅色图面和清楚边界。需要双主题原生图时，分别制作两张并用 `.theme-light` / `.theme-dark` 切换。不得用滤镜反色原始证据图，也不得声称固定图片会自动适配主题。生图 prompt 分开写“准确上图文字”与“构造说明”，不让坐标、像素数值、草稿说明进入图片。

## 让图形承担关系

参考案例先看实际图片，记录它怎样让人先认出对象、再看出关系：向量用分格条，矩阵用网格，数据集用可分组单元，缓存用成列的块，差距用共同尺度下的距离。沿用对象形态、位置和颜色，操作直接改变这些对象的分组、数量、位置或连接；文字就近命名和补条件。主流程统一从上到下或从左到右，输入、操作、输出之间保留连续连线；共享参数与数据在实际操作处汇合，不能让绕行线看起来像无含义的大边框。先确定对象与锚点，再安排连线，最后放标签；连线避开字形，折线只在必要转向处用小圆弯，箭头落到对应对象边缘并留出间隔。用本稿材料重构，不从网页文案推断图面，也不只借配色。短暂浏览应先看出流向、分组或差异，再读标签核实；若仍需逐框读句子才能明白，图还需重构。通用文字框仅用于实际模块、阶段或边界，不作为所有概念的默认形状。分格数量若不等于真实维度、样本数或容量，图注明确它只表示结构；比例图则必须与实际数值一致。复用构造见[图解样例](../demos/content/README.md)，不要求每篇使用全部类型。

| 解释任务 | 图面构造 | 实际验收 |
|---|---|---|
| 成对差异 | 共用尺度与基准；端点值贴近点，范围线或括号标差值；必要时保留原始点 | 遮去重复说明后仍能看出哪组更大、差多少；距离与数值一致，不用每行独立缩放 |
| 连续状态 | 同一输入贯穿前后图，保留对象、位置与颜色；明确新增、保留、移除和失效范围 | 能沿同一对象找到变化及触发条件；互斥状态不叠加，静态图不冒称可执行动画 |
| 综合权衡 | 将共享对象画一次，独立对象分别保留；连线落到实际依赖对象；执行阶段另用明确顺序 | 图能回答哪些成本可共享、哪些仍需承担；数据依赖不误作时间轴，未测耗时不画比例 |

标题给出主判断后，证据页不在侧栏、图注再次复述。图旁保留必要口径、条件和解释；删去重复侧栏时同步扩大主图或表格。小红书将横向复杂图按关系重排为上下对照，不能直接缩小到标签难辨；390px预览发现孤字或孤数字尾行时，先改句长和语义断行，保留正文字号，不全段设为不换行。

## 用动画解释变化

当算法步骤、数据流、shape 变化或几何演化比静态图更易理解时，按所选辅助图模式制作可控动画（HTML 模式使用内联 SVG）；所选工具无法满足真实执行与控制要求时如实说明限制，不静默换模式。同题的主解法与补充解法分别判断，适合展示过程的每个解法各做一段对应动画，放在该解法附近；纯公式或封装库调用不伪造内部过程。算法动画先选具体输入，按正文代码或伪代码生成执行轨迹；在同一画面保留数据对象的身份与位置关系，随操作更新指针、数值、容器成员、连线或访问状态，同时显示当前操作、判断条件及更新结果。步数由执行过程决定，不套固定四步；不能省略理解核心机制所需的比较、分支或状态更新。图形须解释题目中的机制：柱高与面积按数值比例绘制，窗口和二分画候选范围，栈/队列关联原数据并画成员进出，链表标清断开与新建的连接，DP 连接实际读取的前驱和写入格。变量面板、代码高亮和状态文字只作辅助，不能代替对象之间的关系；先查看代表性关键操作，再批量制作。流程框依次高亮、说明文字轮播、静态步骤淡入和装饰运动均不算算法动画。用户主动播放，支持暂停、前后步、拖动进度和重置；不无限循环，离开视口或页面隐藏时暂停，另保留可读的静态执行摘要。

现有 `figure[data-animation]` 接口将 SVG 直接子组 `data-step` 按文档顺序累积揭示，`data-caption` 解释该步；它只控制透明度，适合静态推导的逐步阅读，不能直接作为算法执行动画。算法状态替换、数值更新或几何变换须另按真实执行轨迹实现，不能让已失效的指针、栈成员或连线累积显示，也不能用平滑运动伪造不存在的中间状态。减少动态效果偏好下禁用过渡，仍可手动逐步查看。打印和汇报导出使用完整可读的静态执行摘要，不把互斥状态叠在一起；图片弹窗显示当前步骤的静态快照。PNG 本身不能播放动画，小红书仍按静态关键状态重排。

静态推导逐步揭示的例子见 `demos/content/softmax-longform/main.md`：输入、共同平移、指数、归一化，与原文同组数值一致；它不作为算法执行动画的验收样例。每日温度的执行动画应同时保留温度数组、当前下标、存下标的栈与答案数组：对 `[60,59,61]` 从右向左扫描，实际展示比较栈顶、弹出 `1:59`、保留 `2:61`、写入下标差以及入栈，最后得到 `[2,1,0]`。不能用四条结论框代替这些操作。

## 字号服从阅读尺寸与内容

学习和博客共用一套阅读模板；学习按概念依赖广覆盖、细解释，博客聚焦具体知识点简明讲清原理，不主动扩展，不为场景另建布局。以18px正文、舒适行长为起点；读者可调到10–24px，标题、表格、图注和公式随正文保持层级。图片与SVG可点击或按Enter放大，原图注中的条件、公式和链接随图保留；支持按宽高适合窗口、进一步放大、键盘滚动、Esc关闭和返回原阅读位置与焦点。放大视图标题标明当前图像，缩放状态清楚；正文仍保留原图注，无图注的图像不继承上一张说明。标题换行自然，短导语不制造大空白，不每段套容器。代码允许局部横向滚动；长公式优先合理断行，静态图片不能依赖滚动。

长文视觉优先调整标题、导语、章节分隔和阅读节奏：工具栏与正文外边界对齐，场景身份只在工具栏出现，标题区由标题、导语及真实已给的作者/日期构成；标题区、导语、续读提示与正文共用文字栏宽度和左右对齐线，导语自然换行，不用均衡换行把短导语压成半栏。正文宽度默认60%，可用滑条在40%–80%之间调节并恢复默认；正文、标题、图表容器和代码共用同一内容栏，图片及图注在栏内居中，不自动超出正文。图片右下角提供拖动手柄，在栏宽40%–100%之间等比例调整；图注居中并随图面宽度调整，支持恢复原大小、键盘调节和记忆，窄窗口仍不能越过正文边界。主章节（二级标题）之间保留细分隔线和上下留白，明确章节边界；小节以标题层级和留白区分，不另加横线。图注与图形成组，正文和图注通过字号与留白区分。表格使用浅表头、横向分隔和克制的行间距，补充内容用上下细线；代码的语言、文件名与复制操作放在独立工具栏，重点行轻量标记。不能用更多色块、徽章或装饰动画代替层级设计。

公式默认正常展示，按主线选择少量核心关系强调；定义、证明中的中间式和重复引用不自动加框。需要网页级重点时复用`.callout`的中性底色与细强调边，不在内部再叠加黑色公式框；只删除纯排版的框命令，保留数学关系及条件。长文公式外部间距随正文字号变化，重点块内用较紧凑的间距，保留公式本身的排版高度及上下安全留白。调整工作稿的强调时核对变量、运算、条件和公式数量，不修改数学含义。原稿中的排版标记不应成为所有公式同级强调的硬约束。

短行内公式按整体排布，当前行尾空间不足时移到下一行，避免把括号和核心关系割裂。公式宽度限制在正文容器内，较长表达式仍保留合法断行；不对所有公式强制nowrap。实际查看大字号的行内根号、分式及多项表达式，必要时将过长表达式改为合理的独立公式。

长文自绘图仅在图面设置中性底色和边框，图片与SVG在正文栏内居中，图注在下方居中并与图面同宽，缩放后仍跟随图片对齐，用较小字号和紧邻留白形成一组；图注不再重复加分隔线。固定浅底证据图保留`media-plate`的完整图面。文末来源可用`.article-sources`独立整理，标题与出处分行、正常字形，不把长篇出处整段斜体化；保留原链接、图示来源和适用条件。论断附近的引用仍就近放置，不能全部搬到文末。

表格中的纯数值列按内容选择右对齐，使用等宽数字方便逐列比较；说明文字和混合公式列保持自然阅读对齐，不自动猜测所有列的类型。Markdown可用`---:`指定右对齐。表头和表格内的短代码保持完整，空间不足用表格局部滚动，避免拆出孤字或割裂数组表示；表头本身应简短。只在溢出时显示次要字号的滚动方向提示，在表格下方保留相应间距，不遮挡单元格或伸出补充内容面板；方向变化不移动正文。多表格、多代码长文的缩放截图应覆盖各个块，不能只查看每类第一个块。

目录用章节编号、分组间距和小节缩进呈现层级，编号不进入正文标题。目录与正文保持明确留白，整组布局与窗口边缘留出距离；空间不足时展开目录让正文临时让位，关闭后恢复所选宽度。目录右边缘支持左右拖动、键盘调节和宽度记忆，开合与拖动保持当前阅读位置。当前小节同时标明所属章节；目录过长时只滚动目录容器以保持当前项可见。文末的短结尾也应被正确选中。引言可略大于正文，但不重复增加彩色容器。

小红书1080px画布以38px正文、1.45行距、60px开篇标题、48px正文页标题、44px小标题为起点，左右版心留白84px；390px展示时38px约为13.7px。主标题与正文形成清楚层级，独立封面的标题和导语成组；正文可选图文、开放对照或有序步骤，连续图片不机械重复同一种结构。复用`academic.css`的`.card-lead`、`.card-claim`、`.card-comparison`和`.card-steps`，只按内容需要选用，不把普通段落全套成卡片；`.card-claim`只标必要的归纳或条件。图注34px，图标签按最终显示大小核对，低于12px应重排，不能依赖放大；页码可较小。横向关系过小则重构图，不用装饰文字填空。汇报使用下述 Quarto 字号层级，必要图标签至少18px，并查看完整1280×720导出。

汇报样式独立维护在`assets/content/report.css`，以[Quarto 默认演示](https://quarto.org/docs/presentations/revealjs/demo/)为基础视觉语言，统一封面、正文、双栏和表格；其他案例可用于改善信息组织、图表标注和页型比例，统一到当前字体与配色，不拼接不同主题的外观。正文英文与数字内嵌原版 Source Sans Pro，中文回退思源黑体；标题统一使用思源黑体500字重，避免混排中的字面和黑度失衡。1280×720 页内，中文正文以32px为基准，沿用 Quarto 的相对比例：普通标题1.6em、小标题1.3em、封面标题2.5em；表格24–26px、条件22px。页边距为上56px、左右80px，正文行距1.5，标题行距1.3；封面显式选用`slide-cover`，标题和32px导语成组居中。正文页从顶部左对齐，默认白底、深灰字与少量蓝色，仅可切换纸白背景，不提供深色。先按中文实际字面校准整套比例，不直接套用英文字号，也不对各页分别缩字。常规页优先沿用原版的段落、列表和左侧说明／右侧证据双栏；两栏顶边对齐，表格避免词组拆成孤字。数值进入表格或图表，不默认做独立的超大数字页；比较标注靠近对应数据。标题简明，放不下先调整文案与分页。避免额外分类眉题、整段着色标题、无含义的分隔框和重复课题名，留白保持清楚的分组而非用装饰填空。目录位于左下，展开为深色侧栏；备注和配色工具同在底部，页码位于右上，底边细线显示进度，导出仅保留页内页码。一个讲解任务仍可跨页，必要条件清楚可读；封面不是默认第一页类型。

汇报的主要图表或机制图可用`figure.report-figure`：图面与页面同底色，默认无外框、无内边距，按比例铺开，图注20px并紧邻图面；默认最大高度330px只是起点。流程与角色分工通过文字分组、细线与必要连线表达关系，仅当容器本身有边界含义时加框。按证据需要调整SVG的viewBox与显示高度，减少无效空白；必要标签至少18px，不能把长文图直接缩小后交付。标题、图、图注须一起落在正文安全区；一个讲解任务可跨页呈现图表、比较与解释，复杂图应调整构图或拆页，不靠继续缩小标签。原生缩放逐页检查，并覆盖各图放大和关闭后的页序。

汇报数据表突出需要比较的关键行列，纯数值右对齐并使用等宽数字；必要时添加相对明确基准的变化量。重点单元格可用`--accent-soft`或`--compare-soft`作底色，文字保持`--text`，其余单元格保持中性。连续色阶需对应真实数值和明确范围，不同量纲不能共用大小排序；颜色之外保留数值、符号或标签。折线图呈现时间或有序连续变量的变化，条形图比较类别，关键差距直接标注；坐标、单位、基准和必要条件可见，不用截轴或失真比例夸大差异。图表与短文字共同支持判断，不再用段落重复列出图表的全部数值。

## 成品检查闭环

- 长文与汇报以桌面使用为目标，不另做手机适配验收。学习/博客检查明暗首屏、全部正文区、图解、公式、表格、代码和结尾；汇报仅检查白底页与纸白背景切换。核对100%、150%、200%缩放及实际提供的字号调节、图片放大；区分真实浏览器缩放、CSS布局缩放和DPR，只记录实际执行方式。整页截图供覆盖核对，分屏截图用于细读；章节标题截图不代表整章已看完。
- 汇报查看全部白底页与PNG，核对纸白背景切换，确认能迅速辨认成果或本页判断，并检查整组页面的论证衔接、证据联系、数据差异与布局重心。逐页逐句检查标题、副标题、正文、图中标签、图注、表下注、页脚、小字和讲者备注，全部都应属于本次实际汇报；备注默认收起、可主动开合、导出时隐藏也须验证。小红书查看全部纸白原图和390px宽预览，核对上下文、页序和最终读者可见文案。
- 搜索“稿子示例”“排版示例”“占位文案”“待补充”“此处插入”等制作残留只是辅助；还要识别没有这些关键词的文档不足解释、制作建议和会前待办，移到工作记录，不能藏进小字或讲者备注。正常代码示例、必要教学标注、真实来源与研究限制保留；实际进展和后续研究计划按汇报目的简明表达，不能靠删除证据边界让文案看起来干净。
- 机器检查记录边界、实际SVG标签大小、颜色对比度和可疑文案；位图内文字、信息密度、技术关系与美观仍须目视核对。文字对比度检查不等于完整无障碍认证。
- 修改正文、HTML或图片后重新检查。只有机器检查通过、可疑项处理完成且所有成品实际查看后，才标记 `completed` 并汇总短路径。
- 阅读功能随视觉一起检查：代码复制与换行保真、章节链接直达、折叠区内公式、续读提示及恢复位置。默认折叠和全部展开都要查看，避免把隐藏内容漏出检查范围。
- 字号测试在长文中追踪当前文字，不只检查控件数字变化；原生缩放截图还要核对像素尺寸和实际画面，避免错误裁图得到空白或截断截图却被计作通过。
