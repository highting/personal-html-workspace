# 两种模式共用的图文组织规则

本页用于小红书图文：按[场景 Prompt](../prompts/scenes/rednote.txt)先选小主题，正文统一经 HTML 排版为 3:4 PNG，按需穿插辅助解释图，发布配文只作摘要；HTML＋SVG 或 ImageGen 的选择只用于非正文视觉。图片内独立讲清所选问题，不将原稿全量搬入图片。

## 图像类型

**正文页**承载所选主题，用短而连贯的段落讲清问题与核心机制，保留必要定义和条件。可用简单例子、准确白话或关键关系替代长推导，不能只列结论；不要求每页有公式或图。先完成范围取舍与删减，再在完整语义边界分页，每页都应推进理解，不机械截断原稿或靠增页保住所有旁支。

**辅助解释图**是默认图解类型，配合同页或相邻正文解释一个难以直接想象的关系，不承担整篇文章的介绍、推导和总结。是否独立成页取决于图文关系与可读性，不由类型名称决定；两套比较仍遵循正文页复用规则。

整篇稿件转图文时，先形成完整场景稿，依[共同 Prompt](../prompts/common.txt)完成内容修订和读者视角修订；配图规划同步进行，稿件稳定后再确定页序，注明正文页／辅助解释图、原文位置、讲解目标与制作方式。默认流程是“完整稿 → 内容修订 → 读者视角修订与图文分工 → HTML 排版及辅助图制作 → 写发布摘要 → 检查完整图片序列”。不要求机械交替、固定页数或额外封面，首张正文页可直接开篇。制作两套时完成并复用相同的 HTML 正文图片，保持页序一致，只比较辅助图的制作方式。

## 自动选点与数量

- **整篇稿件转图片组**：从全文提炼适合本次阅读的主线，原稿是材料范围而非逐字搬运要求；明确要求全文保留时遵从用户。先删重复与非必需旁支，再按理解障碍选择图解；必要内容的页数随语义与手机可读性确定，不用固定页数限制，也不无限加页回避取舍。
- **仅给博客／长文配图，或指定局部概念与推导**：在指定范围内选择辅助解释图并注明插入位置，不制作整套正文图片。
- **明确指定图片数量**：遵从本次请求，不自行附加图片；未限定数量时按理解收益与可读性决定。

配图数量按[共同Prompt](../prompts/common.txt)由理解障碍、解释价值和重复程度决定，不设置默认数、数量区间或最低数量。审核正文时主动逐段寻找值得图解的关系，对每个候选写明“帮助理解什么、读者应看出什么、放在哪里”，确认有新增解释收益就制作，不因已有图较多而舍弃。文字足够清楚且图无新增作用时可不配；不能以装饰或重复图凑数。用户已指定类型、数量、顺序或选点时遵从指定。简短展示页序或候选后直接制作，不把规划变成等待确认的关卡。HTML 分页按完整图意组织，不能只依靠自动切句决定图片内容；必要时每张图单独一个 Markdown 文件，按页序汇总 PNG。

## 辅助解释图

先确定关系，再选择最小且充分的构造：向量如何更新、分解或投影，长度／方向／角度怎样变化，不同作用如何竞争或抵消，约束如何影响位置，公式某项有什么几何意义。

主要面积留给对象、空间关系与变化过程。图中只保留变量和短标签，必要方向、角度、长度、约束、条件，以及与画面直接对应的少量公式。更新式可对应首尾相接箭头，投影式可对应垂线和投影向量；保留公式的依据是它与画面的关系，不追求覆盖率。

理解主线必需的理由可与图同页，用简短文字或关键等式说明；确需独立展开或本页容量不足时，再放相邻正文页。不默认展开连续数学推导，其余扩展保留原稿。辅助图保留就近理解必需的标签、条件或结论，避免重复侧栏与无信息增量的总结条。图注说明读者应看出的关系，图形已说清的内容不再重复写一遍。

## 发布标题与配文

发布标题与封面标题不使用第一人称，直接点出主题、核心关系或结论，以准确清楚为先，避免自我叙事、夸张反差和故作悬念。封面尤其应把文章的核心论点放在主标题中，不仅写一个用于解释的概念或观察方式。配文采用作者第一人称，像分享自己的阅读笔记，轻松、自然、口语化，不写成论文摘要或交付说明，也不出现“用户提供的原稿”“本组共若干正文页”等制作视角的表述。

配文仍只作简短摘要：带出主题、核心问题和自己的理解，必要时自然引导看图；不逐页复述全文，不靠长配文补齐缺失正文。标题写入 `标题.txt`，配文写入 `配文.txt`，与最终 PNG、`预览.html` 一起放在 `output/<短名>/`；工作稿可另外保留。两种模式共用同一份标题与配文。来源和制作检查记录放在交付说明中，不混入可直接复制的配文。

验收时先不读摘要，按图片顺序检查概念、因果或推导连接和结论是否完整；需要依赖长配文才能看懂时，应补足正文页。
